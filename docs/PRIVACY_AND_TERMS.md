# 隐私、条款与数据权利

本仓库提供上线所需的产品告知与数据删除闭环，但不能替代运营主体的法律审查。正式
开放前，运营者应根据实际主体、部署地域、供应商合同、日志平台和业务模式审核页面
文案，并保存审批记录。

主要参考：

- [《中华人民共和国个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)；
- [《地图管理条例》](https://www.gov.cn/zhengce/zhengceku/2015-12/14/content_10403.htm)；
- [高德地图开放平台服务协议](https://developer.amap.com/pages/terms/)；
- [高德地图开放平台隐私权政策](https://developer.amap.com/pages/privacy/)。

## 上线配置门禁

生产进程必须配置：

    ZHAOLU_OPERATOR_NAME=<实际运营主体全称>
    ZHAOLU_PRIVACY_CONTACT=<可公开且持续受理请求的邮箱或其他联系方式>
    ZHAOLU_LOG_RETENTION_DAYS=30

前两项缺失时生产进程在监听端口前失败。日志保存天数允许 1–365 天，它用于向用户
公开目标保存期限；运营者还必须在实际日志平台配置相同或更短的自动删除规则，应用
本身无法替外部平台执行日志删除。

公共接口 GET /api/v1/legal-config 只返回文档版本、运营主体、隐私联系方式和日志
保存天数，不返回 Secret。预发布实网烟雾会拒绝未配置的法律文档。

## 用户告知与同意

首页在首次路线规划前要求用户确认当前版本的隐私政策、服务条款与路线免责声明。
同意记录只以文档版本保存在浏览器本地；文档版本变化后自动要求重新确认。隐私政策与
条款分别位于 /privacy 和 /terms，无需登录即可访问。

页面明确说明：

- 路线仅供参考，不替代交通法规、现场判断、医疗建议或紧急服务；
- 路线规划会处理地点、坐标、运动方式、距离和环境偏好；
- 高德承担地点、路线和地图能力，ESA WorldCover 提供公开环境栅格；
- 匿名收藏不是注册账号，不支持跨设备恢复；
- Provider policy 决定路线几何能否导出或持久化；
- 服务不面向不满 14 周岁的未成年人。

## 一键删除

DELETE /api/v1/session 要求匿名 Bearer token。服务端先鉴权，再删除 user_sessions
记录；SQLite 外键级联同步删除该匿名 user id 下的全部 saved_routes 和
field_reports。原 token 随即失效。

首页“隐私与数据”区域会在用户二次确认后调用该接口，并清除本地匿名 token、收藏
状态和同意版本。逐条收藏删除接口继续保留。已经过期或无效的 token 不会触发新会话
创建，页面只清除已失效的本地状态。

## 发布复核

1. 用真实主体和隐私联系信息启动预发布；
2. 确认 /privacy、/terms 和页脚链接可访问；
3. 确认未勾选处理规则时不能规划路线；
4. 收藏并提交反馈后执行“删除全部设备数据”；
5. 确认列表清空、token 清除、旧 token 返回 401；
6. 核对日志平台保存期限与公开天数一致；
7. 核对高德合同、地图资质/备案要求、服务器地域和 WorldCover 数据边界；
8. 由运营、产品和合规负责人共同批准文档版本。
